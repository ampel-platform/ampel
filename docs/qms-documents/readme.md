
# Quality Management System (QMS) Documentation

This repository contains the transformed and translated QMS documents for the in-house medical device software LAMPE at University of Leipzig Medical Center. Site-specific content has been replaced with placeholders. They are intended to serve as a practical example of what corresponding, site-specific QMS documentation might look like.

*Please note:* The documents generally refer to a fixed version of the AMPEL platform and therefore do not correspond to the latest version of the source code.
